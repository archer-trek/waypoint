# Agent 消息无框平铺为文档流，采用素纸与夜读自适应主题

Waypoint 面向 Owner 与 Agent 之间的一对一深度工作交流，渲染时间线时突破传统即时通讯的对称封闭气泡限制：Agent 的内容不画背景与边框，直接作为平铺文档流展开；Owner 的输入保持右侧小巧墨色胶囊；整体界面遵循「素纸（浅）」与「夜读（深）」双生设计，跟随系统外观自动切换。

## Considered Options

- 双方均使用封闭圆角气泡（如经典即时通讯或原型 C「清谈」）。否决：Agent 输出常含长篇 Markdown、宽表格与大段代码，封闭气泡内边距与横向折行会令代码和排版极其局促，限制生产力阅读效率。
- 固定单一浅色或单一纯黑终端主题（OLED Black）。否决：固定浅色在夜间刺眼，纯黑终端风缺乏个人书斋工具的温润感。遵循系统外观并在两端进行精细对比度调优，兼顾了白天纸质阅读感与夜晚沉浸暗光体验。
- 新建 Topic 与设置采用整页替换右侧主工作区。否决：替换主区域会打断当前正在查阅的对话上下文，桌面端改用 480px 居中毛玻璃模态弹窗、移动端改用底部抽屉更能维持上下文连贯。

## Consequences

- Agent 消息容器背景设为透明无外框，正文维持约 42rem 最佳阅读宽度，代码块与表格在宽屏视口下突破正文限制向右延伸并支持独立横向平滑滚动。
- 样式全面依托语义化 Token（`--bg`, `--sidebar`, `--header`, `--ink`, `--muted`, `--line`, `--accent`, `--owner-bg`, `--code-bg` 等），浅色以素纸暖灰白为主调并辅以青墨蓝微点缀，深色以暗岩蓝黑为主调并辅以暖铜琥珀金微点缀。
- 顶部导航栏高度收缩至 44px 紧凑规格，Description 吸顶单行折叠展示；Topic 列表行采用两行式紧凑微排版，状态点精细对齐并支持等宽时间戳。
- 不引入额外的全局第三方字体包，优先使用平台顶级原生字体栈（macOS/iOS 下使用 SF Pro / 苹方，Android 下使用 Roboto / 思源黑体，等宽微标使用 SF Mono / JetBrains Mono）。
