# Agent 消息平铺为柔和微卡片文档流，融合 Grokbot 悬浮岛与素纸夜读主题

Waypoint 面向 Owner 与 Agent 之间的一对一深度工作交流，渲染时间线与界面时突破传统即时通讯的生硬对称与紧绷边框限制：融合 Claude Desktop 的文档展开流、Grokbot 的悬浮动态岛美学、Muse 的数字纸张呼吸感与 t3code 的精密线。Agent 内容采用带 16px 圆角与极低饱和微底色的柔和文档卡片展开；Owner 输入保持右侧小巧墨色胶囊；顶栏与输入盒全面升级为脱离屏幕边缘的悬浮岛；整体遵循「素纸（浅）」与「夜读（深）」双生设计，跟随系统外观自动切换。

## Considered Options

- 双方均使用封闭狭窄气泡（如经典即时通讯）。否决：Agent 输出常含长篇 Markdown、宽表格与大段代码，狭窄封闭气泡内边距与横向折行会令代码和排版极其局促，严重削弱长篇阅读体验。
- 纯透明无框悬空排版 vs 柔和微底色卡片（Soft Card）。修订：原 ADR-0024 的纯透明排版在深色模式与移动小屏上容易导致内容与底层空间缺乏锚定感。引入 Grokbot 风格的 16px 大圆角柔和微底色卡片（浅色 `--card`，深色温润暗岩层 `--card`），既保留了文档流的自然展开与黄金行高（1.65），又赋予了消息清晰优雅的视觉边界。
- 贯穿屏幕两端的传统 44px 吸顶硬条与贴底输入盒。否决：硬边界挤压移动端视口，平铺多个文字操作按键导致标题严重截断。升级为 Grokbot 风格的悬浮三药丸岛（Floating Islands）与脱离底边 14px 的悬浮全圆角输入大胶囊（Floating Capsule Composer），配合 `···` 操作收纳与回到底部浮动圆钮（Scroll-to-Bottom FAB）。
- 列表行引入真实头像与最新消息正文摘要。否决：继续坚持 ADR-0017 与 ADR-0019 确立的 Topic-Centric 核心定位（列表行不放正文摘要以防窥低噪，不下载真实头像），但吸收 Grokbot 极简空灵质感，列表行与顶栏药丸左侧呈现统一样式的轻量 Bot 符号徽章。

## Consequences

- Agent 消息呈现为 16px 大圆角柔和微底色卡片（`--card` 与 `--line-subtle`），文本自然语言段落限宽 `min(42rem, 100%)`，段距 `0.85rem`，黄金行高 1.65；代码块与数据表格在卡片内横向平滑滚动并支持 6px 细弱圆角滑块。
- 顶栏演进为悬浮三药丸岛（Floating Islands）：移动窄屏呈现左侧圆形返回 `<`、中间圆角 Topic 药丸、右侧圆形 `···` 浮层菜单；桌面宽屏右侧悬浮岛外露 Ghost 按键组保障操作效率与测试兼容。
- Description 作为居中悬浮药丸下方的微单行提示，点击平滑展开气泡卡片，不画贯穿横实线。
- 底部 Composer 升级为脱离底边的全圆角悬浮大胶囊（平态浮空 14px，移动端软键盘弹起时平滑贴合键盘安全区），左内嵌圆形 `+` 附件按钮，右内嵌优雅发送键。
- 时间线离开底部超过阈值时，自动浮现 Grokbot 式圆形回到底部悬浮键（Scroll-to-Bottom FAB）。
- 样式全面依托语义化 Token，浅色以素纸暖灰白（`#f8f7f4`）辅以青墨蓝微点缀，深色以温润暗岩墨黑（`#16181d`）辅以暖铜琥珀金微点缀，彻底修复暗色模式下 Shiki 代码高亮对比度。
