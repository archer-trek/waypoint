# Agent 消息彻底无框平铺为纯文档流，顶栏贴顶吸附，输入框单行纯净自适应

Waypoint 面向 Owner 与 Agent 之间的一对一深度工作交流。结合 t3code 极简工程美学对界面进行系统性收敛：顶栏采用标准紧贴式吸顶（不悬浮），仅展示 Topic 名字与 Description，右侧收敛为纯 Icon `···` 操作菜单；Agent 回复彻底不画任何气泡框与卡片背景，直接作为纯净平铺文档流展开；仅 Owner 消息保留右侧圆角气泡；底部输入盒无 Placeholder，初始紧凑单行（仅含左侧纯 Icon 附件入口与右侧纯 Icon 发送按钮），内容超过单行时平滑转为多行展开。

## Considered Options

- Agent 回复画封闭圆角气泡或卡片外框。否决：无论气泡多大或底色多浅，卡片与气泡边框都会在阅读长篇报告、复杂列表与宽表格时产生视觉边界压迫感。彻底移除 Agent 的背景、边框与气泡，使其如高质量文章排版一样自然流动展开，获得最高的长文阅读舒适度。
- 顶栏采用多小岛悬浮漂浮式架构。否决：悬浮岛割裂了视口顶部空间，在移动端容易挤压标题展示。回归紧贴屏幕顶部的标准粘性吸顶条（Docked Sticky Header），中间纵向呈现清晰加粗的 Topic 名字与 Description，不额外堆砌 Bot 标识，标题字体适度放大，视觉层级更清晰。
- 顶栏平铺文字操作按键。否决：文字按键挤占空间导致标题截断。顶栏操作收纳为右侧纯 Icon 的 `···` 操作菜单，通过 `aria-label` 保持完备的无障碍语义。
- 输入框常驻多行或附带长串 Placeholder 占位文字。否决：灰色占位文字带来表单噪点。输入盒彻底去除 Placeholder，初始状态为极简单行卡片，仅保留左侧 `+` 附件与右侧 `↑` 发送纯 Icon；仅在用户输入换行或文本撑破单行时，才平滑自增高为多行。

## Consequences

- Agent 消息容器（`.waypoint-message-row.left .waypoint-bubble`）背景与边框完全透明无阴影，段落自然舒展，正文限宽 `min(42rem, 100%)`，行高 1.65；长代码块与数据表格作为独立元素直接在文档流中平滑横向滚动。
- Owner 消息（`.waypoint-message-row.right .waypoint-bubble`）保留右侧紧凑圆角气泡。
- 顶栏为标准吸顶 Docked Header，背景采用半透明毛玻璃微模糊，去除悬浮边框，中间双行展示 Topic 名字（加大字阶约 1.15rem~1.25rem）与 Description；右侧为纯 Icon 的 `···` 话题操作按键。
- 底部 Composer 无任何占位文本，默认呈紧凑单行（高约 44px），左右分别内嵌纯 Icon 附件与发送按钮，文字超出一行时平滑展开。
