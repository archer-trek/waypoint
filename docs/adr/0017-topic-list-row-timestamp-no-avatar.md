# Topic 列表行显示最近活动时刻，不显示头像

主界面 Topic 列表行右侧展示最近活动时间戳，今天显示具体时刻，跨日精简日期；无消息时取诞生时间。列表行不展示任何头像。

## Considered Options

- 列表行也不显示时间戳，完全纯文本。否决：列表排序本身依托最近活动时间，展示时间戳能让 Owner 快速判断各话题的活跃度与时效。气泡内不展示时刻是为沉浸式长文阅读，列表行作为导航索引需要时间线标尺。
- 采用秒级刷新的相对时间（如“3分钟前”、“2小时前”）。否决：需要常驻定时器刷新大量列表项，且随时间推移文案不断抖动；传统 IM 的日历切分（今天、昨天、月日、年月日）更稳定高效。
- 列表行展示 Bot 头像（或生成首字母占位缩写）。否决：ADR-0012 已定打开 Topic 时标题区不放头像，也不去取头像。Waypoint 是单人专属客户端，列表行不引入头像媒体下载或缩写，多个 Bot 时以文字副标题标识足矣。
- 未确认的本地交出立刻更新列表行时刻。否决：本地未确认交出使用的是本机临时时钟，未经服务器确认。时刻保持以已确认的 `origin_server_ts` 为准。

## Consequences

- 列表行右侧显示最近活动的时间戳。
- 格式化规则按客户端本地日历日：今天显示 `HH:mm`；昨天显示 `昨天`；今年内更早显示 `MM-DD`（随系统区域设置）；跨年显示 `YYYY-MM-DD`。
- 若 Topic 尚无消息，取该 Topic 诞生（建房）的标记时间。
- 未确认或失败的交出不提前修改已显示的时刻，待收到服务器确认回声后更新。
- 列表行不放任何头像（Bot 和 Owner 均不放头像）。只有一个 Bot 时不显示 Bot 名字，多个 Bot 时副标题显示 Bot 名字（按手写名、显示名、localpart 顺序回退）。
- 列表行是否标出未确认转圈或失败红叹号，不在本决定里。
