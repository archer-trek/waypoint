# 气泡靠左右区分，不显示时刻

一条 Topic 里，Owner 的消息靠右，绑定的 Agent 靠左。气泡上不写名字，不放头像，也不显示时刻。日历日变了，才在消息之间放日期分隔。

## Considered Options

- 每条气泡盖时钟，或点按才看精确时刻。否决：Hermes 的进度文字也是气泡。一对一里时刻是噪音。未确认的消息还没有服务器时间。
- 只靠顺序，或在气泡上写名字。否决：滚到中间，一句「好」分不出是谁。Owner 没有展示名。没写名字时退路是 localpart，写到气泡上就像用户 ID。
- 用头像区分。否决：打开 Topic 时名字已经可见。不为这条身份去取头像。
- 把加入、邀请、改名，或第三人的消息也画成气泡。否决：新建 Topic 时的邀请不该堆在对话开头。第三人不是第三边。

## Consequences

- 未确认的消息也靠右。它长什么样不在本决定。
- 打开 Topic 时，Agent 的名字和 Topic 的名字同时可见，不另开一页。名字用名册那套：手写名，否则显示名，否则 localpart。不显示完整用户 ID。只有一个 Agent 时，列表行仍不出现这个名字。标题区不放头像。
- 日期分隔按这台设备的本地日历日，比较已确认、且会画出来的相邻消息的服务器时间。文案随区域设置：今天、昨天，或只写日期。第一条上面没有分隔。空过的日子不补。分隔不是消息，不推进已读位置，也不占左右。编辑不改这一天。两台设备时区不同，分隔可以不同。
- 未确认的消息不撑开新的一天，也不重排。分隔插在跨日的那条已确认消息之前，所以未确认的可能暂时出现在分隔上面。确认后再算。
- 加入、邀请、改名、改 Description 不画成气泡。第三人的消息不显示，也不参与分隔。绑定不合法时不编名字，只显示 Owner 的消息，靠右。
- 列表上的时刻和头像、不可用怎么提示、标题是否钉住，不在本决定。
