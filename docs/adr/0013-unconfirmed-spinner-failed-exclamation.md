# 未确认用转圈，失败用红叹号

未确认和失败都留在原来的气泡上。未确认只在气泡旁放一个转圈。失败换成红叹号，点一下就按原样再发一次。丢掉只在失败气泡的菜单里。

## Considered Options

- 气泡下面写「未确认」「失败」，并放常驻按钮。否决：成熟的 IM 用标记，不写状态句。丢掉也不和审批按钮放在一起。
- 未确认用时钟。否决：WhatsApp 是这样，但气泡上的时钟会被看成时刻。时刻已经不放在气泡上。
- 点红叹号再确认，或放回输入框。否决：微信是点一下就重发。失败不填回输入框已经定过。
- 重试时挪到时间线末尾，或一次清掉全部失败。否决：气泡留在原处。丢掉是逐条的。
- 只靠滑动丢掉，或未确认也能丢掉。否决：两端用同一个菜单。未确认还在重试队列里。

## Consequences

- 画面上不写「未确认」「失败」，不写错误码，也不写 Not Delivered。无障碍名称仍用这两个词。
- 点红叹号不进输入框，不清草稿，不挪位置。没网就回到未确认，由重试队列再试。再失败又变回红叹号。
- Topic 不可用时红叹号还在。点了马上又失败，不解释原因。不可用怎么另外提示不在本决定。
- 永久失败时，重试队列里的那一项仍丢掉。文字和已复制的附件留在这条本地时间线上，直到重试成功或被丢掉。再发一次是新的一次尝试，确认后仍是同一条气泡。
- 菜单里只有丢掉，不显示时刻。点一次就从这台设备消失，不再确认，也没有撤销。
- 两者都不算未读，不推进已读位置。另一台设备看不到。
- 列表行要不要标出转圈或红叹号，不在本决定。
