# Topic 列表行以前导圆点与标题加粗标示未读，打开 Topic 时主标题栏固定钉住

Topic 列表行以左侧前导实心圆点配合 Topic 名字加粗提亮标示「未读」，并通过左、中、右三段固定分区与既有列表行元素正交共存；打开 Topic 后，顶部主标题栏始终固定钉住（Pinned），可选 `Description` 默认单行截断并支持点按展开。

## Considered Options

- 列表行仅靠 Topic 名字加粗区分未读，或把未读圆点放在右侧时刻旁。否决：列表行无头像且无消息正文预览，仅靠字重变化在双端扫视时对比度不足；右侧已承载未确认转圈/失败红叹号与最近活动时刻，把未读指示放到左侧前导区最醒目且不与右侧状态抢占焦点。
- 将未读、`不可用`、`正在回应`、转圈/红叹号等全部堆在右侧时刻旁。否决：多种正交状态同时出现时会互相挤压截断，按职责分为前导、中部文本与右侧尾随三段能保证布局稳定。
- 打开 Topic 后顶部标题区随对话时间线一起滚走，或将长 `Description` 完整多行永久固定在顶栏。否决：顶栏滚走会让 Owner 在翻阅长历史时失去当前 Topic 与绑定 Bot 身份提示、管理操作入口以及常驻警示横幅锚点；而永久展开多行 `Description` 会在小屏与软键盘弹起时严重侵占对话可视高度。

## Consequences

- **列表行未读指示**：当一条 Topic 处于「未读」状态时，列表行左侧（标题前方）展示实心圆点指示器，同时将 Topic 名字加粗提亮；变为已读后圆点消失、标题恢复常规字重。即便该 Topic 处于 `不可用` 置灰状态，只要已读位置之后仍有未读消息，前导未读圆点依然保留。
- **列表行三段式固定分区与正交共存**：
  - **左侧前导区**：放置「未读」实心圆点（未读时同时加粗主标题）。
  - **中部文本区**：主行展示 Topic 名字（单行截断）及紧随其后的轻量 `不可用` 标签、置顶标记；次行展示多 Bot 时的绑定 Bot 名字与 `正在回应` 状态提示（单 Bot 且无 `正在回应` 时不占次行）。
  - **右侧尾随区**：并列展示发送状态指示（未确认转圈或失败红叹号，最多一个，红叹号优先）与最近活动时刻。
- **打开 Topic 时顶部标题区固定钉住（Pinned）**：
  - 顶部主标题栏始终固定钉住在时间线视口顶部，不随滚动消失；常驻展示 Topic 名字、绑定的 Bot 名字（单 Bot 时也显示）与管理操作入口（改名、改 Description、置顶、删除，以及移动端返回入口）。
  - 若该 Topic 带有非空 `Description`，在固定标题栏内以紧凑单行截断展示（为空则不占垂直空间），点按可展开查看完整 `Description`（再点按或滚动时收起，或进入编辑/查看）。
  - 若存在 `不可用` 警示横幅或 token 失效重登横幅，紧贴在固定主标题栏下方常驻。
