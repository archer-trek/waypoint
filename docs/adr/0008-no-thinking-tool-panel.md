# 不做思考/工具面板

正在回应只认消息上的 👀。思考和工具不是独立事件，Waypoint 不把它们收成面板。Hermes 的进度文字就是普通消息，编辑按渲染决定收成一条。

## Considered Options

- 用「被编辑过」或「以 emoji 开头」收成可折叠面板。否决：最终回复在流式打开时也是编辑。没有稳定标记，面板会藏起真回复。
- 要求 Owner 打开思考进度，或关掉工具进度。否决：不改 Hermes 配置，也不把显示开关写进首次连接。打开了仍然没有结构化事件。

## Consequences

- 👀 还在，正在回应就在，包括回答已经出现后 Hermes 延迟撤回的那几秒。typing 不是状态。
- ✅ 和 ❌ 留在原消息上，不升级成第二套状态，也不藏。
- 列表上显示一次正在回应。打开 Topic 时，挂着 👀 的那条消息下面也显示。
- 审批和选择器不是这个面板。它们靠 Agent 预种的 reaction 认出。
